# llms.txt

このサイトは、HTML を解析しなくてもエージェントが読める形でドキュメントを公開しています。

- `/llms.txt`: すべてのドキュメントページの索引です。各ページに 1 行の説明が付きます。
- `/llms-full.txt`: すべてのドキュメントページの全文を 1 つのファイルにまとめたものです。
- ドキュメントの URL の末尾に `.md` を付けると、そのページを Markdown で取得できます。例: `/en/docs/installation.md`

どのドキュメントページにも「Copy page」ボタンがあります。ページを Markdown としてコピーし、チャットに貼り付けられます。
