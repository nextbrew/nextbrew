# ソースからのビルド

nextbrew は、既定では bottle をインストールします。formula をソースからビルドしたいときは、
`--build-from-source`（または `-s`）を渡します。

```sh
nb install --build-from-source <formula>
nb upgrade -s <formula>
```

お使いのプラットフォーム向けの bottle がない formula では、`nb install` は勝手にビルドせず、停止してこのフラグを案内します。

## ビルドの仕組み

Linux では、ビルド環境は Homebrew の superenv に倣います。依存関係のパス
（include、lib、pkg-config）を Homebrew と同じように設定し、nextbrew の prefix にある
依存パッケージを使って formula をビルドします。ログは formula ごとのログディレクトリに出力されます
（ビルド中は `NEXTBREW_LOGS`）。

formula の `install` は Homebrew の portable Ruby で実行します。nextbrew がビルド用に
ダウンロードします（できないときは `PATH` 上の `ruby`）。

## ビルドできるもの

次の 25 個のうち、Linux では全部、macOS では 24 個がソースからビルドできます（GitHub の
ubuntu-latest と macos-latest、2026-10-26 計測）。jq、tree、htop、fd、ripgrep、fzf、wget、
curl、git、tmux、zoxide、sqlite、readline、pcre2、zstd、lz4、xz、pkgconf、libyaml、gmp、
bat、gh、lua、oniguruma、libevent。macOS の readline は、ミラーが返したパッチのチェックサムが
合わず失敗しました。また gmp は GCC 15 ではビルドできません。GCC 15 の既定の
C23 を gmp の `configure` が受け付けないためで、Homebrew でも同じです。

`create`、`audit`、`bottle` などの開発者向けコマンドは予定していません。
bottle があるなら、bottle を使ってください。
