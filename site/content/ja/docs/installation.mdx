# インストール

nextbrew は macOS（Apple Silicon）と Linux（x86_64 と arm64）で動きます。

## インストールスクリプト

```sh
curl -fsSL https://nextbrew.dev/install | bash
```

Homebrew が入っていても、そのまま残ります。nextbrew は専用の場所に入ります。

| 環境 | 場所 |
| --- | --- |
| macOS | `/opt/nextbrew` |
| Linux | `/home/nextbrew/.nextbrew`（すでに `/opt/nextbrew` か `~/.local/share/nextbrew` がある場合はそちらを使います） |

## 手動でダウンロード

[GitHub Releases](https://github.com/nextbrew/nextbrew/releases) から、使っている環境の
`nb` と `nbx` をダウンロードし、`SHA256SUMS` と照合してください。
