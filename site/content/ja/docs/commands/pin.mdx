# nb pin / unpin

```sh
nb pin [OPTIONS] <FORMULAS>...
nb unpin [OPTIONS] <FORMULAS>...
```

`nb pin` は、インストール済みの formula をアップグレード時も今のバージョンのままにします。
`nb unpin` は、再びアップグレードできるようにします。どちらにも、共通の `--auto-init`、
`-v`/`--verbose`、`-q`/`--quiet` のほかにオプションはありません。

## 例

```sh
nb pin postgresql@16
nb list --pinned
nb unpin postgresql@16
```

`nb uninstall` は、`--force` を渡さない限り、pin された formula を拒否します。

## brew との違い

これらのコマンドは Homebrew と同じように動きます。[互換性](/ja/docs/reference/compatibility)を参照してください。
