# 互換性

- **Native**: Homebrew と同じように動きます。
- **Partial**: 一部のオプションやパッケージに制限があります。
- **Unsupported**: 明示的なエラーで失敗します。

formula のコマンド、cask のすべての artifact とコンテナ、bundle、services は、変更のたびに統合テストが macOS と Linux で実際に動かして確かめています。`nb migrate` も CI で実際の Homebrew を nextbrew に移して確かめています。

| 機能 | 状態 |
| --- | --- |
| formula: install、uninstall、upgrade、outdated、list、info | Native |
| formula: link、unlink、pin、autoremove、deps、uses、search | Native |
| cask: app、suite、dmg、zip、tar、binary | Native |
| cask: フック（`*_steps`） | Native。未知のステップや失敗があると、インストールはロールバックされる |
| cask: pkg と installer | Native |
| cask: upgrade | Native。自己更新する cask は名前を指定したときだけ |
| cask: uninstall stanza と `--zap` | Native |
| cask: `--language` | Native。既定はシステムの言語 |
| Bundle（Brewfile） | Native。`flatpak`、`winget` と各拡張を含む。`build-from-source` と formula オプション以外のビルド `args` は理由つきで失敗 |
| Services | macOS（launchd）と Linux（systemd）で Native。ラベルは `dev.nextbrew.<formula>` |
| Tap | 対応しています（`nb tap`、`nb trust`）。サードパーティの tap は、信頼すると読み込まれます。 |
| Homebrew からの移行（`nb migrate`） | Native。formula、cask、tap、pin、service |
| ソースからのビルド | ネイティブ。Linux で主要 formula 25 個中 24 個がビルドできる（C、Rust、Go）。開発者向けコマンド（create、audit、bottle）は予定なし |

コマンド名、オプション、終了コードは Homebrew に従います。nextbrew が Ruby を実行するのはソースからのビルドのときだけです。
理解できないステップは、黙ってスキップせず報告します。
