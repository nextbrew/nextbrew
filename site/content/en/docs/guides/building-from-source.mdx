# Building from Source

nextbrew installs bottles by default. To build a formula from its source
instead, pass `--build-from-source` (or `-s`):

```sh
nb install --build-from-source <formula>
nb upgrade -s <formula>
```

When a formula has no bottle for your platform, `nb install` stops and suggests this flag rather than building on its own.

## How it builds

The build environment follows Homebrew's superenv on Linux: dependency paths
(include, lib, pkg-config) are set up the way Homebrew sets them, and the
formula is built with its dependencies from the nextbrew prefix. Logs go to a
per-formula log directory (`NEXTBREW_LOGS` inside the build).

The formula's `install` runs on Homebrew's portable Ruby, which nextbrew
downloads for the build (else the `ruby` on your `PATH`).

## What builds

These 25 formulae build from source on macOS and Linux (GitHub's
macos-latest and ubuntu-latest, 2026-10-25): jq, tree, htop, fd, ripgrep,
fzf, wget, curl, git, tmux, zoxide, sqlite, readline, pcre2, zstd, lz4, xz,
pkgconf, libyaml, gmp, bat, gh, lua, oniguruma, libevent. gmp does not with
GCC 15, whose C23 default its `configure` rejects (the same under Homebrew).

Developer commands such as `create`, `audit` and `bottle` are not planned.
Prefer a bottle when one exists.
