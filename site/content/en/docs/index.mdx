# Introduction

nextbrew is a Homebrew-compatible package manager written in Rust. It installs
Homebrew's official bottles and casks without needing Ruby or Homebrew itself.
It ships as two binaries: `nb`, the package manager, and `nbx`, which runs a
formula's command without linking it.

## Principles

- **Homebrew's data, not a copy of Homebrew.** nextbrew reads Homebrew's public
  JSON API and installs Homebrew's official bottles. It keeps no package
  definitions of its own.
- **Correctness before speed.** A fast install that skips a post-install step,
  or a cask that cannot be removed again, is not a result.
- **Never skips silently.** If nextbrew does not support something, it says so.
  It does not pretend the step succeeded.

nextbrew is early software. Expect breaking changes before 1.0.
