# llms.txt

The site publishes its docs in forms an agent can read without parsing HTML.

- `/llms.txt`: an index of every docs page with a one-line description.
- `/llms-full.txt`: the full text of every docs page in one file.
- Append `.md` to any English docs URL for that page as Markdown, for example `/en/docs/installation.md`. The `.md` copies exist only for English pages.

Every docs page also has a Copy page button that copies the page as Markdown, to paste into a chat.
