---
title: nb autoremove
description: Remove formulae that were only installed as dependencies and are no longer needed.
---

# nb autoremove

```sh
nb autoremove [OPTIONS]
```

## Options

| Flag | Meaning |
| --- | --- |
| `-n`, `--dry-run` | List what would be removed without removing it |
| `--auto-init` | Initialize without prompting |
| `-v`, `--verbose` | Increase output verbosity |
| `-q`, `--quiet` | Suppress output, only show errors |

## Examples

```sh
nb autoremove --dry-run
nb autoremove
```

## Differences from brew

`nb uninstall` runs this for you, as `brew uninstall` does. Set `NEXTBREW_NO_AUTOREMOVE` to turn that off.
This command is Native.
