# nb tap / trust

```sh
nb tap [OPTIONS] [NAME] [URL]
nb trust [OPTIONS] [NAMES]...
```

`nb tap` with no arguments lists the tapped repositories. With `user/repo` it
taps that repository, fetching it from `github.com/user/homebrew-repo` unless
you give a `URL`. `nb untap` removes taps.

`nb trust` marks third-party taps, formulae, casks or commands as trusted so
they may be loaded; `nb untrust` reverses it. Official taps are always trusted.

## nb tap options

| Flag | Meaning |
| --- | --- |
| `-f`, `--force` | Tap even a tap nextbrew reads from the API |
| `--custom-remote` | Change an installed tap's remote to `URL` |
| `--auto-init` | Initialize without prompting |
| `-v`, `--verbose` | Increase output verbosity |
| `-q`, `--quiet` | Suppress output, only show errors |

## nb trust options

| Flag | Meaning |
| --- | --- |
| `--tap`, `--taps` | The names are taps |
| `--formula`, `--formulae` | The names are formulae |
| `--cask`, `--casks` | The names are casks |
| `--command`, `--commands` | The names are commands |
| `--auto-init` | Initialize without prompting |
| `-v`, `--verbose` | Increase output verbosity |
| `-q`, `--quiet` | Suppress output, only show errors |

## Examples

```sh
nb tap
nb tap user/repo
nb trust --tap user/repo
```

## Differences from brew

Third-party taps are supported through `nb tap` and `nb trust`, as described
here. Taps that Homebrew serves
through its API (homebrew/core, homebrew/cask) are read from the API, not cloned.
