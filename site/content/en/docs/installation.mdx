# Installation

nextbrew runs on macOS (Apple Silicon and Intel) and Linux (x86_64 and arm64).

## Install script

```sh
curl -fsSL https://nextbrew.dev/install | bash
```

Homebrew, if you have it, is left untouched: nextbrew lives in `/opt/nextbrew`.

## Manual download

Download `nb` and `nbx` for your platform from
[GitHub Releases](https://github.com/nextbrew/nextbrew/releases) and check them
against `SHA256SUMS`.
