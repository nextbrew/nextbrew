# Compatibility

- **Native**: behaves like Homebrew.
- **Partial**: some options or packages have limits.
- **Unsupported**: fails with an explicit error.

Formula commands, every cask artifact and container, bundle and services are
exercised end to end on macOS and Linux by the integration tests on every change,
and `nb migrate` moves a real Homebrew installation into nextbrew in CI.

| Feature | Status |
| --- | --- |
| Formulae: install, uninstall, upgrade, outdated, list, info | Native |
| Formulae: link, unlink, pin, autoremove, deps, uses, search | Native |
| Casks: app, suite, dmg, zip, tar, binary | Native |
| Casks: hooks (`*_steps`) | Native; an unknown step or a failure rolls the install back |
| Casks: pkg and installer | Native |
| Casks: upgrade | Native; self-updating casks when named or with `--greedy`, `--greedy-latest` or `--greedy-auto-updates` |
| Casks: uninstall stanza and `--zap` | Native |
| Casks: `--language` | Native; the system's languages by default |
| Bundle (Brewfile) | Native, including `flatpak`, `winget` and the extensions; build `args` other than `build-from-source` and formula options fail with the reason |
| Services | Native on macOS (launchd) and Linux (systemd), labels `dev.nextbrew.<formula>` |
| Taps | Implemented (`nb tap`, `nb trust`); third-party taps must be trusted before they load. |
| Migrating from Homebrew (`nb migrate`) | Native: formulae, casks, taps, pins and services |
| Building from source | Native: all 25 popular formulae tried build on Linux and macOS (C, Rust, Go); developer commands (create, audit, bottle) are not planned |

Command names, options and exit codes follow Homebrew. nextbrew runs Ruby only
to build from source. A step it does not understand is reported, not skipped silently.
